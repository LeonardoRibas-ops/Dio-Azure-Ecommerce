# 🛍️ Mercado DIO - E-commerce na Cloud

Esse projeto é um app de cadastro de produtos feito com **Streamlit**, onde os dados vão direto para um banco **Azure SQL** e as imagens dos produtos são armazenadas na **Azure Blob Storage**. Tudo isso rodando suave na cloud! 🌩️

---

## 🚀 Funcionalidades

- Cadastro de produtos com nome, preço e imagem
- Upload automático para Azure Blob
- Salva info no banco Azure SQL
- Front-end em Streamlit ✨

---

## 📦 Tecnologias Usadas

- 🐍 Python
- ⚡ Streamlit
- 🧊 Azure SQL Database
- 🗂️ Azure Blob Storage
